Keyboard Shortcuts ​

The bottom bar always shows the keys that work in the current context. Press ? for the full list.

Global ​

KeyAction
ctrl+kCommand palette: open an operation, run the spec / a tag / flows, switch environment, history, copy as cURL
?Toggle help (ignored while typing in a field)
ctrl+vSwitch environment: the named environments of .lazyapi/config.yml (or .env* files when there is no config), then "none"
escCancel the request in flight (while the spinner is shown)
ctrl+cQuit

Request List ​

KeyAction
↑/k, ↓/jMove
enterOpen in the editor
sSend the selected request. POST/PUT/PATCH/DELETE ask for confirmation
[ / ]Previous / next response tab (Body, Headers, Cookies, Timeline, Checks, Console)
pgup / pgdownScroll the response
oCycle the server
/Filter by method, path, summary or tag (esc clears)
ctrl+nNew draft request
dDuplicate
xDelete
ctrl+tEdit tags
RRun the spec's read-only operations in the runner
HOpen the history
qQuit

Request Editor ​

KeyAction
tab / shift+tabNext / previous field: method → server → URI → Send → tabs → response
alt+enterSend from any field
enter (on Send)Send
F5Run the test script on the last response (sends first if there is none)
ctrl+oSave to the spec (definitions, test script)
ctrl+eSave the last response as an example in the spec (outside text fields and editors, where ctrl+e is "end of line")
ctrl+xOpen a text Body or the Tests tab in $VISUAL / $EDITOR
alt+cCopy the request as cURL (with the active environment's server and credentials)
{{ or $nameOpen the variable menu; ↑/↓ choose, tab inserts, esc closes
alt+fFormat the JSON body
ctrl+z / ctrl+yUndo / redo in Body, Tests and the description
shift + movement, alt+aSelect in the code editor (esc clears)
ctrl+cCopy the focused field's value, or the code editor's selection (with nothing to copy: quit)
ctrl+vPaste into the focused field or editor (alt+v too; alt+x cuts in code editors)
escLeave tab content, then back to the list

Tabs ​

KeyTabAction
← / →(tab bar)Switch tab
enter(tab bar)Edit the tab content
ctrl+qParamsAdd query parameter
ctrl+pParamsAdd path parameter
ctrl+gHeadersAdd header
alt+tBodyChange the body type (none, JSON, XML, text, forms, file…)
ctrl+gBody (form)Add form field
ctrl+fBody (multipart)Make the row a file part / a text field
ctrl+rAuthAdd auth scheme
del / ⌫AuthDelete the selected auth scheme

Response panel (when focused) ​

KeyAction
[ / ] or 1–6Body / Headers / Cookies / Timeline / Checks / Console
rToggle raw / pretty body
fjq filter for the body (empty enter removes it)
/Search the response; n / N jump between matches
ctrl+yCopy the response body
↑ ↓ pgup pgdown, mouse wheelScroll

Runner ​

KeyAction
↑/k, ↓/j, g / GMove through the results
enterOn a flow: expand / collapse its steps. Otherwise: focus the details
tabFocus the result details (response tabs, search, jq); tab/esc back to the list
FShow only failures
eOpen the operation in the editor
RRun again
escStop the run in progress, then back

History ​

KeyAction
↑/k, ↓/jMove
enterReplay: open the request in the editor with the values it was sent with
dDiff the response with the previous response of the same operation
xDiff the response with the example saved in the spec
XDelete the history shown (asks y/N)
tabFocus the response details
escClose the diff, then back
