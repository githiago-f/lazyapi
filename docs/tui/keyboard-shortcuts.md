# Keyboard Shortcuts

## Global

| Key | Action |
|-----|--------|
| `q` | Quit |
| `Ctrl+C` | Kill / Force quit |
| `?` / `h` | Toggle help |

## Navigation

| Key | Action |
|-----|--------|
| `k` / `↑` | Move up |
| `j` / `↓` | Move down |
| `h` / `←` | Move left |
| `l` / `→` | Move right |
| `Enter` / `Space` | Select |
| `Esc` | Back / Blur |
| `Tab` | Next field |
| `Shift+Tab` | Previous field |

## Request List

| Key | Action |
|-----|--------|
| `Enter` | Open request |
| `Ctrl+N` | New draft request |
| `d` | Duplicate request |
| `x` | Delete request |
| `/` | Filter list |

## Request Editor

| Key | Action |
|-----|--------|
| `Ctrl+S` | Save to spec |
| `Ctrl+E` | Save response example |
| `Enter` (on Send) | Execute request |

### Tab-specific chords

| Keys | Tab | Action |
|------|-----|--------|
| `n` + `q` | Params | Add query parameter |
| `n` + `p` | Params | Add path parameter |
| `n` + `h` | Header | Add header |
| `n` + `a` | Authorize | Add auth scheme |
| `x` + `a` | Authorize | Delete selected auth scheme |
| `F5` | Tests | Run Lua test script |
